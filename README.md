## Lesson 1 · Character Set Explorer
- **Explore:** type text; each character's denary code, binary and whether it fits in 8-bit ASCII / 16-bit Unicode / 32-bit Unicode, plus total size in bits and bytes.
- **The order of codes:** click a character; shows how its code is worked out from 'A' = 65 and highlights the 32s bit (upper/lower case).
- **Challenges:** randomly generated questions at A Must / B Should / C Could, auto-marked with worked explanations.

Nothing is saved or sent anywhere. GCSE simplification: Unicode treated as fixed 16 or 32 bits per character.
